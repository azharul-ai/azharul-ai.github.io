# azharul-ai.github.io

Personal portfolio and engineering blog hosted with GitHub Pages.

## Site structure

- `index.html` - portfolio homepage
- `blog/index.html` - article listing
- `blog/posts/` - published article pages
- `css/style.css` - shared portfolio styles
- `css/blog.css` - blog-specific styles
- `feed.xml` - RSS feed
- `sitemap.xml` - search-engine sitemap

The site is intentionally static so it remains easy to host and maintain on
GitHub Pages without a separate server or personal domain.
